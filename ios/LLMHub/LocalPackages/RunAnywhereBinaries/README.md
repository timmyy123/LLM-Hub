# Archived RunAnywhere binaries

These seven XCFrameworks were retained from `ios/runanywhere-sdks-latest/sdk/runanywhere-swift/Binaries` when the unused RunAnywhere source package was removed. They are archival binaries and are not linked by the LLMHub app. GGUF inference uses the direct llama.cpp package; LiteRT models use LiteRT-LM.

Keep this directory if the precompiled RunAnywhere libraries are needed later. It does not contain the RunAnywhere Swift SDK module or replace its source package.
